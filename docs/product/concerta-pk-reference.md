# Concerta PK Reference (근거 자료)

콘서타(Concerta, methylphenidate OROS) 혈중 농도 곡선을 모델링하기 위한 근거 자료입니다. FDA 승인 라벨 데이터와 PLOS One 논문(서방형 methylphenidate 방출 모델)을 종합했습니다.

> 안전 경계: 아래 값은 성인 평균 모집단 추정치입니다. 그래프는 교육용 추정이며 실제 혈중 농도·효과·개인 반응은 크게 다를 수 있습니다. 의료 조언이 아닙니다.

## 출처·모델 원칙

출처·모델·표현 원칙은 [pk-model-principles.md](pk-model-principles.md)를 따른다. 콘서타는 **FDA 라벨**을 1차 출처로 하고, Weibull ER 방출 형태는 동료심사(PLOS One)를 방법론 근거로 사용한다.

## 1. 단계별 시간대 (Time-Course)

콘서타 농도 곡선은 **초기 급상승 + 점진적 상승**의 2단계 방출 패턴을 보입니다.

| 구간 | 시간 | 설명 |
|------|------|------|
| 초기 피크 (IR) | 0 ~ 1시간 | 알약 겉면 즉시방출(IR) 코팅 용해 → 1시간 이내 첫 농도 정점 |
| 점진적 상승 (ER) | 1 ~ 6시간 | OROS 삼투압 시스템이 약물을 서서히 방출. 내부 농도 구배 설계로 방출 속도가 시간에 따라 증가 → 혈중 농도 우상향 |
| 최고 농도 (Tmax) | 6 ~ 10시간 | 모든 용량에서 평균 투여 후 **6.8시간(±1.8)** 에 최고 농도 도달 |
| 감소기 | 10시간 이후 | 최고점 이후 **이중 지수적(biexponential)** 감소, 반감기 약 3.5시간 |

## 2. 수치 데이터 (18mg 기준, 성인 36명 평균)

| 파라미터 | 값 (평균 ± SD) | 비고 |
|----------|----------------|------|
| Cmax (최고 혈중 농도) | 3.7 ± 1.0 ng/mL | 18mg 투여 시 최고점 수치 |
| Tmax (최고점 도달 시간) | 6.8 ± 1.8 시간 | 곡선이 꺾여 내려가기 시작하는 지점 |
| AUCinf (곡선 하 면적) | 41.8 ± 13.9 ng·h/mL | 전체 약물 노출량 |
| t½ (반감기) | 3.5 ± 0.4 시간 | 감소기 기울기 결정 |

## 3. 수학적 모델링: Weibull 방출 함수

PLOS One 논문은 서방형(ER) methylphenidate 방출을 **Weibull 함수**로 설명합니다. 콘서타 방출 곡선 시뮬레이션에 응용할 수 있습니다.

```txt
Release(t) = Max × [ 1 − exp( −( (t − T_lag) / A )^b ) ]
```

| 기호 | 의미 | 콘서타 참고값 |
|------|------|---------------|
| `Max` | 전체 용량 중 ER 성분의 양 | 전체의 **78%** |
| `T_lag` | 약물 방출 본격 시작 전 지연 시간 | 논문 모델 약 **4시간** |
| `A` | 척도 매개변수 (방출의 시간 규모) | — |
| `b` | 모양 매개변수 (`b>1` → S자형, `b=1` → 지수 상승) | — |

**전체 농도 = IR 방출분 + ER 방출분(Weibull)** 의 합.

- IR(즉시방출): 전체 용량의 **22%**
- ER(서방형): 전체 용량의 **78%**

## 4. 용량 비례성

- Cmax와 AUC는 용량(18mg / 36mg / 54mg)에 **선형 비례** 증가.
- 예: 36mg 곡선은 18mg 곡선 대비 약 2배 높은 정점.

## 5. 모델링 요약

> 초기 1시간에 작은 IR 봉우리 → 6.8시간까지 ER 완만 상승 → 이후 반감기 3.5시간을 따라 biexponential 감소.

## 합의된 모델링 방식 (2026-06-27)

콘서타 농도 곡선 구현 시 아래 방식으로 합의했습니다.

### 결정 1 — 방출→소실 convolution (정확 모델)

- Weibull(ER)과 IR 방출을 **"방출 입력 함수"** 로 두고, 1-compartment 반감기 3.5h 소실 커널 `exp(−ke·t)` (`ke = ln2 / 3.5`)과 **수치 합성곱(convolution)** 한다.
- `전체 농도 = IR 방출분 + ER 방출분(Weibull)` 을 동일한 소실 커널로 적분.
- 반복 복용은 각 doseEvent의 기여분을 시점 이동해 합산(누적이 물리적으로 일관).
- **핵심 성질**: `AUC = (방출 총량) / ke` 이므로 전체 노출량은 방출 모양과 무관 → 스케일은 AUC로, 모양(Tmax/Cmax)은 방출 파라미터로 분리 보정 가능.

### 결정 2 — raw + percent 둘 다 반환

- `concentrationSeries` 각 점은 `{ hour, raw, percent }`.
- `raw`: ng/mL 절대 추정값 (근거값 Cmax 3.7 검증용).
- `percent`: 피크 대비 % (UI 표시·정규화용).

### 결정 3 — 근거 3값에 캘리브레이션 (18mg 기준)

자유 파라미터를 아래 목표값에 맞도록 고정한다.

| 목표 | 값 |
|------|-----|
| Tmax | 6.8 시간 |
| Cmax | 3.7 ng/mL |
| AUCinf | 41.8 ng·h/mL |

- 스케일(`F/V`): `AUC = (F·Dose/V)/ke = 41.8 @18mg` 로 고정.
- 모양 파라미터(IR 방출속도, ER Weibull `A`·`b`·`T_lag`): Tmax 6.8 / Cmax 3.7 에 맞춰 튜닝 후 프로필에 고정.
