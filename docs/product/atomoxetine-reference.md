# Atomoxetine PK Reference (근거 자료)

아토목세틴(스트라테라 외 국내 6종 = 동일 프로필) 표현 근거 자료입니다. 비자극제(NRI)이며 **누적형(accumulation)** 으로, 당일 단일 곡선 대신 ① 효과 누적 진행 + ② 정상상태 일일 곡선으로 표현합니다([데이터 출처 정책](concerta-pk-reference.md#데이터-출처-정책-2026-06-27), 설계: [atomoxetine-steady-state](../exec-plans/completed/atomoxetine-steady-state.md)).

> 안전 경계: 성인 평균/임상 경과 기반 추정. 교육용이며 의료 조언이 아닙니다. 효과가 느려도 임의 중단 금지, 의료진과 상의.

## 1. 두 개의 시간 척도 (핵심)

- **혈장 농도(시간 단위)**: 빠르게 흡수(Tmax 1~2h), 반감기 짧음 → 혈장 정상상태는 며칠 내 도달.
- **임상 효과(주~개월 단위)**: 점진적으로 누적. 개선 중앙값 약 3.7주, **약 5개월(~20주)까지 계속 상승 후 평탄화**. → 당일 곡선이 효과를 대표하지 못하는 이유.

## 2. 수치 데이터 (FDA Strattera 라벨)

| 파라미터 | 값 | 비고 |
|----------|-----|------|
| Tmax | 1~2 시간 | 빠른 흡수 |
| 반감기 (EM) | 5.2 시간 | 정상 대사자 |
| 반감기 (PM) | 21.6 시간 | CYP2D6 저대사자 |
| 생체이용률 | 63% (EM) / 94% (PM) | |
| 단일용량 Cmax/AUC | (라벨에 없음) | 전체 라벨 확인 → 정규화 표시 |
| 효능 시험 기간 | 6~10 주 | FDA Clinical Studies |
| 위약 대비 유의 개선 | ~8 주까지 확인 | FDA Clinical Studies |

- **전체 FDA 라벨을 확인한 결과 단일 용량 Cmax/AUC 절대값이 없다** → 정상상태 일일 곡선은 **정규화(%)** 로 표시(검증된 결정).

### 효과 궤적 (peer-reviewed, PMC3120776)

| 시점 | 강한 개선(≥40%) 확률 |
|------|----------------------|
| 4주 | 47% |
| 12주 | 76% |
| 26주 | 85% |
| 52주 | 96% |

- 개선 중앙값 **3.7주**, 관해 중앙값 14.3주. "점진적으로 개선되며 **약 5개월까지 계속 상승 후 평탄화**".
- 모델 앵커: **onsetWeeks 4**(≈개선 중앙값, ~25%), **stabilizeWeeks 20**(~5개월 평탄화, ~90%).
- FDA 시험(6~10주)은 짧아 초기 상승만 관찰 → "8주 최대"가 아니라 초기 구간일 뿐.

## 왜 S곡선(Weibull)인가 — 곡선 모양의 근거

끝점(0주 0% / 평탄화 ~90%)은 FDA·문헌 데이터로 앵커링되지만, 그 사이를 잇는 *궤적의 정확한 점별 값*은 하드 데이터가 없다. 그럼에도 직선·로그형이 아닌 **S곡선(sigmoid/Weibull)** 을 채택한 약리학적 근거:

- **직선형 ✗**: 매일 일정 비율로 오르는 약효는 비현실적.
- **로그형 ✗**: 초기에 훅 오르고 평탄 — 이는 **자극제(콘서타·페니드)** 의 특징이지 비자극제가 아님.
- **S곡선 ✓ (지연 발현)**: 아토목세틴은 뇌 신경망의 **구조적 적응(수용체 적응)** 을 유도 → 초기 1~2주 물밑 진행(완만) → 임계점 이후 가파른 체감 → 수개월에 걸쳐 평탄화. 이 **수용체 적응 PD 모델**은 항우울제·비자극제 ADHD 약의 표준 약력학 모델이며, 보고된 점진적 궤적(Clemow & Bushe 2015; PMC3120776)과 일치.

요약: FDA의 *수치*는 없지만, 현대 약리학의 *정설*을 수학적으로 가장 잘 번역한 형태가 S곡선이다. 곡선의 점별 값 자체는 교육용 근사로 명시한다.

## 표현 방식

- **효과 누적 진행**: Weibull CDF 기반 단조 증가 곡선(발현 ~25%, 안정화 ~90%). `prototype/effect-model.js`.
- **정상상태 일일 곡선**: 기존 PK 모델 재사용(immediate, t½ 5.2h, Tmax ~1.5h), 정규화 표시. 반감기 5.2h·24h 간격이면 누적 미미 → 단일 복용 ≈ 정상상태.
- CYP2D6 PM은 별도 곡선 대신 주의 문구로 처리(이번 범위).
