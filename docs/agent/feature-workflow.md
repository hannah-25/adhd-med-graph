# Feature Workflow

1. Confirm the feature goal and non-goals.
2. Read product and architecture docs.
3. Create an execution plan if the feature changes module boundaries or data shapes.
4. Add or update tests first when feasible.
5. Implement model logic before UI wiring.
6. Keep medical safety copy visible for user-facing graph features.
7. Run `npm run agent:verify`.
8. Update docs and generated maps.
