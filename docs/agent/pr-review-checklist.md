# PR Review Checklist

- Requirements are satisfied.
- Existing documented behavior is preserved.
- Domain rules are respected.
- Architecture layer boundaries are respected.
- API compatibility is considered.
- Data migration impact is considered.
- Error handling is explicit.
- Authentication and authorization impact is clear.
- Tests or harness checks were added or updated.
- Related docs were updated.
- Performance impact is acceptable.
- Security and privacy impact is acceptable.
- Operations and deployment impact is clear.
- Rollback path is realistic.
- No secrets or personal health data are committed.
- No restricted-license source was copied into tracked code.
