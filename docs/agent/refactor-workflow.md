# Refactor Workflow

1. State the behavior that must remain unchanged.
2. Read module and dependency rules.
3. Keep changes scoped to one boundary at a time.
4. Avoid moving reference-source code into tracked prototype code.
5. Run checks after each meaningful step.
6. Update architecture docs if boundaries become clearer.
7. Track deferred cleanup in [../exec-plans/tech-debt-tracker.md](../exec-plans/tech-debt-tracker.md).
